A Note a record links and that was born inside it is that record's own output, so archive files the pair: each such live Note is retired and moved beside the record, and the reply names what it carried. Everything else the record spawned stays live — an open Question born inside a closed Task is a debt the dashboard raises, not history. Nothing distinguishes a proof link from any other note link in the format, so the rule is the one the edges can state, and a Note that outlives its origin should not carry that origin's name. The whole cascade is judged before a byte moves: a report the notebook cannot read, or whose archived home is taken, refuses the move with every record where it was. The reports move first, so an interruption leaves the record live and the next call finishes it; a call on an already-archived record moves nothing, because whatever travelled with it travelled then. The alternative shapes were a Check finding for the split, which would have the tool report a state only the tool creates, and a convention kept by hand, which nothing enforces.
