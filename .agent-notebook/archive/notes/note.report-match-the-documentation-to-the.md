# Documentation author voice

Revised the README, landing page, product explanation and contribution guide using the author's Russian messages as the writing sample. The prose now states personal aims and workflow preferences in the first person and explains customization with concrete examples. Removed slogan-like parallel phrasing, abstract editorial headings and repeated statements about product value. The technical references and the factual corrections from the public documentation review remain intact.

The README now explains why the author wants work with an agent to survive the session, what care went into the CLI, and how the supplied skills describe the author's own method. The design page distinguishes personal workflow choices from record invariants. The contribution guide invites actual experience with commands and modified skills without prescribing a generic contribution ritual.
