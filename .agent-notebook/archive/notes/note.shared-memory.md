Keep concise shared project memory that connects domain language, decisions, external sources and daily work. A new agent must recover relevant context, continue the intended Task and distinguish project knowledge from personal practices. Support parallel sessions, several people and roles, and readers without the CLI or its skills. Record only information worth carrying forward. Validate commands, persistence and workflows against explicit scenarios, preserve existing knowledge through supported migration, and keep project-specific workflow extensions separate from the installed skill.
