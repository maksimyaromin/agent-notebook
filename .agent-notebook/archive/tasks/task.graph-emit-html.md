anb graph [--for <hub>] [--ready] writes one self-contained HTML artifact, data embedded: task-centric map, id-only tiles colored by state, full record in a modal, blocked-by (solid) and origin (dashed) edges unlabeled, mentions only inside the modal. Slices: full map, epic branch, ready lens. No server; the CLI stays the single write path.
- 2026-08-30 Maksim Yaromin: Design settled before code. (1) anb graph [--for <hub>] [--ready] [--out <path>], defaulting to anb-graph.html in the working directory: a derived artifact is not a record, so it never lands in the notebook where check and list would have to learn to ignore it, and the reply names where it landed. (2) The Core answers the model, the shell renders and writes it. Storage speaks only in paths under the notebook root, so the artifact is the shell's write, the same way the report close --note ingests is the shell's read; html.rs joins text.rs and json.rs as a third rendering. (3) Every slice reads the whole notebook, live and archived. One rule, and it is the only way finished work has a picture at all — the epic branch needs its closed children to show a counter. (4) The layout is computed in Rust — rank by the longest blocked-by chain among the tiles on the map, slot within the rank — so the artifact is deterministic and testable and the page needs no layout library. Script opens the modal and does nothing else. (5) Self-contained means self-contained: inline style, inline script, data embedded as JSON. No network, no server, and no write path but the CLI.
- 2026-08-30 Maksim Yaromin: Shipped and green. anb graph [--for <hub>] [--ready] [--out <path>] emits one self-contained HTML file: task-centric tiles carrying the id alone, coloured by state and greyed when filed, a hub carrying its progress counter, blocked-by solid and origin dashed and neither labelled, and the full record — envelope, body, mentions — in a modal the tile opens. Ranks run down the page, each Task below everything it waits on, tiles as wide as the longest id the map carries. - 2026-08-30 Maksim Yaromin: Reworked after the maintainer's note: the first attempt hard-coded CSS and JS as Rust string constants beside json.rs and hand-rolled the layout. That is not a subsystem. Replaced by crates/anb-graph, whose look and behaviour are plain files — index.html, theme.css, graph.json, app.js — carried as data and replaceable one at a time: anb graph --eject-theme <dir> hands a reader the ones the tool draws with, --theme <dir> draws with theirs, and a file no page reads is refused by name rather than ignored. The maintainer's picture is Obsidian's graph view, so the default arrangement is force-directed (fcose) with a layered one (dagre) a button away; the page is Cytoscape, chosen because its stylesheet is a JSON document, which is what makes every colour and shape data instead of code. Measured by download, not memory: engine 669 KB inlined, a 42-task map 940 KB, no network. Interactions: hover lifts a neighbourhood and dims the rest, click opens the record, search fits to hits, chips filter by state, finished work and born-from lines toggle. Proved by driving each emitted page headlessly through jsdom — which caught a real defect Rust could not see: fcose never registered because cose-base needs layout-base on the window first.
- 2026-08-30 claude-code: Reshaped after the maintainer's review of the emitted page. `anb graph` now prints the graph as data by default — nodes[n]{id,state,archived,degree,epic,title} and edges[n]{from,to,kind} in the reply family's shape, versioned under --json as {"v":1,"slice":…} — and draws the picture only under --out. Slice flags apply to both paths: --for, --ready, --focus <id> [--depth n] (ancestors and descendants, default 1 hop), --archive (the archive is off by default), plus --full for each record's envelope and body and --all to lift the row bound. The picture is static SVG emitted by Rust, one <g data-id> per Task and one <polyline> per edge, so a review harness can anchor a comment to a Task; dagre 3.1.1 (49 KB, the only vendored script) arranges it in the browser and a force pass draws the web. Names are measured with getComputedTextLength, reserved in the layout, and decluttered by priority against the boxes getBoundingClientRect reports, so no two names overprint — proved by opening real pages headlessly and reading back the placed boxes. The theme apparatus (--theme, --eject-theme, graph.json, tools/graph-probe) and Cytoscape with its four layout packages are deleted; the page is self-contained and reaches no network. Fixed on the way: a record living in both the live and the archived home draws one tile, the live one.
