The shipped workflow skill keeps principles and concise patterns in SKILL.md; separate files are reserved for heavy reference or reusable tools. Structure the main skill around purpose, triggers, a core pattern, quick reference, application and common mistakes. Write direct instructions to the agent and explain non-obvious choices. Teach judgment with scenarios and contrasts instead of prescribing a fixed document pipeline. Keep the existing anb skill identity and Rust source layout. Validate changes with an explicit scenario, no-guidance baseline and guided applications; distinguish observed behavior from guarantees.
