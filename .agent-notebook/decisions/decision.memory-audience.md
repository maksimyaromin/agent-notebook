Project records describe shared work and knowledge. Authorship is provenance, not the audience of a domain model or standing rule. Personal work filters must not hide project knowledge. Personal practices live outside committed project records, with separate project-specific and cross-project locations; recall composes these locations and labels their source without silently overriding conflicting rules. Session continuation is local execution state, separate from the accountable person and from record frontmatter. Two sessions may work on different Tasks without holding each other. When no session focus establishes a unique continuation, expose the alternatives instead of guessing from dates or ids. Shared reference validation depends only on the shared notebook, never on files in an author’s home. This design avoids audience and lease fields on every record, and keeps Markdown canonical. A database or persisted relevance score is unnecessary: derive relationships and readiness from the current graph, and let agents consolidate verified outcomes into reusable knowledge. Biological memory motivates selective recall, provenance and consolidation; it does not justify uncalibrated forgetting counters or automatic deletion. Existing records and dates remain readable, and migration is explicit and recoverable.
