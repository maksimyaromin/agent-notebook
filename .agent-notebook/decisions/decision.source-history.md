Ordinary creation and lifecycle operations use the host date. Explicit directory import preserves source IDs, dates, attribution, bodies and archive placement after validating the prospective notebook. No imported marker or fabricated author is required. Record uncertain dates and provenance in the body or source links. Preview and retry must not overwrite existing divergent records.
