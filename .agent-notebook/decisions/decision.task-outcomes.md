Close completed work with an attributed outcome in the Task: result, verification and any remaining limit. Inline text and a body file are equivalent input routes. Links may cite evidence, but completing a Task does not create a Note or require a special proof format. Create a separate Note only when its knowledge needs an independent lifetime.
