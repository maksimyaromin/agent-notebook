# @supolka/agent-notebook

The `anb` command: a project's working memory as typed records in plain files, read and written by any coding agent.

```sh
npx -y @supolka/agent-notebook --help
```

This package holds the shim; the binary for your platform arrives as an optional dependency, one package per platform, and nothing runs at install time. Documentation: https://agent-notebook.supolka.dev. Source: https://github.com/maksimyaromin/agent-notebook.
